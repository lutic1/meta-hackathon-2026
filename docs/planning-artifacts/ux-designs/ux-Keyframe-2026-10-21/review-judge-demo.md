# Keyframe UX contract: judge's-eye demo review

Luis Ticas · 2026-10-21

## Verdict

**Honest, but not yet legible where the points are.** The spines get demo honesty right. The Disclosure banner is server-composed, sits on every surface (the Build view included), and no scrim ever dims it. The mode indicator declares Local or Hosted and the Cache state. Real and Decoy cards are kept identical, and the rejected Trickster Card carries the Validator's plain reason. A judge will not catch Keyframe faking anything.

What the judge *sees*, though, undersells what was built:

1. **The Meta models are named in one place only, the Build view, and the Build view is cut 0, the first Cut taken.** The wizard metaphor hides the models everywhere else: role lines, Stage list, Hosted landing, Greeting and Cards never name `muse-spark-1.3`, `sam-3.1`, `muse-image-1.0` or Llama 3.2 3B. If cut 0 is taken, the product shows no model attribution at all. Even with the Build view, its Model table drops the PRD's "what it did" column and sits below the fold.
2. **The verification story reads as a rubber stamp.** A stored Room always passes, so the verdict table is always eight green rows. The pass rows print the rule's *failure* message beside "pass". The Dry run rows never say what a Dry run is. A Regeneration never says what the Validator caught. On the Capture screen, validate and dry run merge into one "Testing the room" row that reports no result.
3. **Three proof beats are visual non-events.** The persuasion attack clears the field and re-fades the same line. The accepted Decoy changes nothing visible and names no Puzzle. The local Llama's phrasing looks exactly like the verbatim fallback, and the fallback is silent, so a verbatim Rung could be passed off on camera as local phrasing.
4. **The hosted path does not show the product in ten minutes.** The landing opens on a caveat line and four unnamed 24 px faces. A Demo room runs at full timings: a 90 s nudge, 90 s Rung spacing, and a first Trickster window no sooner than 3 minutes in. A Judge room build gives 2 to 4 minutes of static rows.

None of the fixes needs scope beyond the PRD. Most are copy and placement edits to the spines. Four need a solution-free field the architecture spine does not yet expose, and each is flagged `[NOTE FOR ARCHITECTURE]`.

**Counts:** 1 critical, 9 high, 8 medium, 2 low.
