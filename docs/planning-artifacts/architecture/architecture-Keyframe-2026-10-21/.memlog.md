- (event) Headless create from the spec package docs/specs/spec-keyframe (SPEC.md, stack.md, budgets.md, player-profile.md, delivery-plan.md, glossary.md, adopted schema-v1.md) and its memlog; altitude feature, purpose build-substrate; brownfield-light: a 400-line Python scaffold (src/providers ModelProvider ABC with mock and Meta stub, src/config Settings from env, pytest under tests/) whose conventions are ratified, not re-decided
- (constraint) [ADOPTED from spec] 16 GB M1, no CUDA; Guide model Llama 3.2 3B on Ollama on the Mac only; SAM 3D Objects only via fal.ai in Tier 2; Meta Model API standard tier; hosted mode on Modal CPU with an async job; Schema v1 frozen Mon Oct 26; solutions never in a prompt; profile stays on the player machine; raw photos never in the repo
- (decision) AD-1 paradigm: hexagonal core with a pipes-and-filters build pipeline. Binds all. Prevents I/O and vendor calls leaking into puzzle logic. Rule: src/domain is pure (no network, no filesystem, no clock reads); src/council and src/pipeline depend only on domain and on ports declared in src/providers/base.py and src/pipeline/ports.py; adapters (providers, infra) implement ports and never import each other; src/api depends inward only. Dependency direction is a diagram in the spine
- (decision) AD-2 one data shape: Schema v1 is realized once as Pydantic models in src/domain/schema.py; the same JSON travels the HTTP API, the job artifacts and the client; client TypeScript types are generated from the backend JSON Schema (GET /schema) and committed, never hand-written, with a test that fails when stale; JSON keys stay snake_case end to end. Binds CAP-1 to CAP-6, CAP-11. Prevents two shapes of Room or Puzzle
- (decision) AD-3 solution boundary: Room carries solutions; RoomView (domain/redact.py) is the only type a prompt builder accepts, produced by one redact function that drops solution, lock payload targets and validator-only fields; council modules take RoomView by type and the test suite runs validator rule 5 over every rendered prompt fixture. Binds CAP-2, CAP-4, CAP-5. Prevents a solution reaching Spark or Ollama
- (decision) AD-4 server-authoritative, event-sourced session: the backend session is an append-only event log (click, lock_input, idle_tick, hint_request, trickster_card); SessionStateMachine.apply is the sole writer of locks_open, inventory, current_rung and trickster_window; state is replayed from events; the client renders state and posts events, never infers lock state. Binds CAP-3, CAP-4, CAP-5, CAP-8. Prevents client and server disagreeing on what is open
- (decision) AD-5 model ports: ModelProvider (chat with images, response_schema and reasoning_effort; segment; reconstruct3d; generate_image; transcribe) is the only way to reach a model; HintPhraser is a separate port implemented only by the Ollama adapter and by a verbatim adapter, so no hosted provider can ever phrase a hint; adapters: mock, meta (Chat Completions for the council, Responses for sam-3.1), openai_compatible (base_url: Baseten, Fireworks), fal, ollama. Council and pipeline receive ports by injection; no adapter import outside src/providers and src/api. Binds all model-facing capabilities. Prevents scattered API calls and a cloud Guide
- (decision) AD-6 guarded calls: every hosted adapter call passes SpendLedger.guard(kind, estimate) then Cache.get_or_call(key) inside the provider package; key = sha256(downscaled image bytes) + prompt + model id + schema hash; CACHE=off bypasses the cache, never the ledger; the ledger counter persists through the JobStore port (disk locally, Volume hosted). Binds CAP-1, CAP-2, CAP-5, CAP-7, CAP-9, CAP-12. Prevents uncounted spend and re-billed photos
- (decision) AD-7 build as a persisted job: POST /builds stores photos and returns a job id; the pipeline runs stages ingest, architect, segment, author, validate, dryrun, scene in order, persisting job state and stage artifacts through JobStore and ArtifactStore after each stage with per-stage timings; no request blocks on a stage; GET /builds/{id} reads persisted state only. Binds CAP-1, CAP-2, CAP-10. Prevents in-memory job state and the 150 s timeout killing a build
- (decision) AD-8 profile ownership: the browser is the system of record for the player profile and per-room results (IndexedDB under PROFILE, a JSON file under cut 2); a session start carries only the derived block; the server never persists derived or profile data and never joins its transient session log to a profile; hosted sessions and their artifacts are deletable as a unit. Binds CAP-4, CAP-6, CAP-13. Prevents profile data landing on the Volume
- (decision) AD-9 one codebase, two modes: MODE=local|hosted selects adapters only (JobStore, ArtifactStore, HintPhraser, ledger persistence) in src/infra; no mode branch outside src/infra and src/api wiring; the HTTP API is identical in both modes. Binds CAP-10 and every capability it hosts. Prevents a forked hosted code path
- (decision) AD-10 clocks: a Clock port supplies all time; the session clock applies DEMO_TIMESCALE to the nudge threshold, rung spacing and Trickster window; the build clock never applies it and stamps stage timings and the capture timer. Binds CAP-1, CAP-4, CAP-5, CAP-8. Prevents the timescale touching the capture proof
- (decision) AD-11 scene contract: Tier 1 scenes are Three.js textured planes with polygon hotspots in the scene graph Tier 2 reuses; hotspot id equals interactable id; the client sends interactable ids and lock inputs, never puzzle logic; the DOM-only fallback keeps the same hotspot id contract. Binds CAP-3, CAP-11. Prevents a second scene model for Tier 2
- (decision) AD-12 validation as the write gate and immutable rooms: validate(room) and dry_run(room_view) are pure functions; a Room is written to the ArtifactStore only after validate passes (and dry_run unless cut 4); a TricksterEdit produces a new Room version that is written only if validate passes, never an in-place mutation; the rejected card references the unchanged version. Binds CAP-2, CAP-5. Prevents an unvalidated room reaching a player
- (decision) AD-13 errors and retries: stages raise typed errors (ProviderError, ValidationError, DryRunError, SpendCapExceeded); the regeneration loop (at most 2, then re-capture) lives in the pipeline, never in adapters; adapters retry once with backoff on 429 and 5xx only; the API error envelope is {error: {code, message, stage}}. Binds CAP-1, CAP-2, CAP-9. Prevents double retry loops and silent provider failures
- (decision) AD-14 configuration: environment only, read once by Settings (existing src/config.py) and injected; flags MODE, PROFILE (client), CACHE, SPEND_CAP_USD, DEMO_TIMESCALE, DEMO_TRICKSTER, MIN_CONTAINERS, GUIDE (ollama|verbatim); no module reads os.environ directly. Binds all. Prevents drift in how flags are read
- (decision) AD-15 demo mode: DEMO_TRICKSTER=scripted replaces only the proposal source (a recorded proposals file in the artifacts); the validator and card rendering are unchanged; GET /meta exposes the active mode, flags and disclosure text for the UI and README. Binds CAP-5, CAP-8. Prevents a faked reject
- (decision) AD-16 provenance: every Room carries provenance (model ids, prompt hashes, stage timings, regeneration count, spend per stage) written by the pipeline; the spend log export is derived from the ledger, never hand-kept. Binds CAP-1, CAP-9. Prevents unexplainable rooms in the submission
- (decision) AD-17 ownership and tests for parallel agents: one owner per top-level package (domain, council, pipeline, providers, api, infra, web); a story touches one package plus tests, or declares the port change it needs first; pytest runs offline against the mock provider for every story; adapter tests use recorded fixtures under tests/fixtures; a story is not done until pytest passes offline. Binds all. Prevents merge conflicts and network-dependent tests
- (decision) Consistency conventions: snake_case JSON keys everywhere including TypeScript; ids are prefixed ULIDs (room_, job_, sess_, pz_, ix_, te_); times ISO 8601 UTC with the session clock in milliseconds; structured JSON log lines carrying job_id or session_id; hosted access code as X-Access-Code header; Python 3.13 type hints, pydantic v2 models, ruff defaults; TypeScript strict
